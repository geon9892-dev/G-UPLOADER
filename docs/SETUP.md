# 처음 설정 가이드

## 1. Claude API 키

1. https://console.anthropic.com 에 가입하고 결제 수단을 등록합니다.
2. **Settings → API Keys → Create Key**로 키를 만듭니다.
3. G-UPLOADER 설정의 **1. Claude API 키**에 붙여넣고 **저장 및 확인**을 누릅니다.

모델은 기본값(Claude Opus 5.5)이 글을 가장 잘 씁니다. 비용을 줄이려면 Sonnet 5.5나 Haiku 5.5를 고를 수 있습니다.

## 2. 유튜브 연결 (Google Cloud, 무료)

각자 자기 Google Cloud 프로젝트를 쓰기 때문에 사용량 한도도 각자 따로 받습니다.

1. https://console.cloud.google.com 에서 **새 프로젝트**를 만듭니다 (이름 예: G-UPLOADER).
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3**를 검색해 **사용**을 누릅니다.
3. **API 및 서비스 → OAuth 동의 화면**(Google 인증 플랫폼)
   - 사용자 유형: **외부**
   - 앱 이름, 지원 이메일, 개발자 연락처만 채우고 저장합니다.
   - **대상(Audience)**에서 **테스트 사용자**에 내 구글 계정을 추가합니다.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **데스크톱 앱**
   - 만든 뒤 **JSON 다운로드**를 누릅니다.
5. G-UPLOADER 설정의 **2. 유튜브 연결**에서 **클라이언트 파일 등록**으로 받은 JSON을 고르고, **유튜브 계정 연결**을 누릅니다.
6. 브라우저에 구글 로그인 창이 뜨면 채널이 있는 계정을 고르고 권한을 허용합니다.

### 7일마다 다시 로그인해야 한다면

OAuth 동의 화면이 **테스트** 상태면 구글이 7일마다 로그인을 만료시킵니다. **OAuth 동의 화면 → 앱 게시(프로덕션으로 푸시)**를 누르면 이 제한이 없어집니다. 구글 심사를 받지 않아도 본인 계정으로는 쓸 수 있고, 로그인할 때 "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (앱 이름)(으)로 이동**을 누르면 됩니다.

> 받은 JSON 파일과 키는 절대 깃허브 등에 올리지 마세요. G-UPLOADER는 등록한 내용을 `%APPDATA%\G-UPLOADER`에 암호화해 보관하므로, 원본 JSON 파일은 지워도 됩니다.

## 3. 채널 정체성 파일

설정의 **3. 채널 정체성 파일**에서 바로 고치거나, 직접 작성한 `.md` 파일을 불러옵니다. 섹션 이름(`## 말투`, `## 절대 쓰지 말 것`, `## 고유명사`, `## 설명란 고정 문구` 등)은 그대로 두는 것이 좋습니다. 프로그램이 이 이름으로 금지 표현, 음성 인식용 고유명사, 고정 문구를 찾습니다.

- `## 절대 쓰지 말 것`에서 **"따옴표"로 감싼 표현**은 자동 검사됩니다.
- `## 고유명사`에 채널명, 출연자 이름을 쉼표로 적으면 음성 인식이 정확해집니다.
- `## 설명란 고정 문구` 아래 내용은 모든 설명 끝에 그대로 붙습니다.

## 4. 음성 인식

기본값 **자동**이면 NVIDIA 그래픽카드가 있을 때 가장 정확한 `large-v3-turbo`를, 없으면 CPU 사양에 맞춰 `medium` 또는 `small`을 씁니다. 모델은 처음 한 번만 내려받습니다(약 0.5~1.6GB).
