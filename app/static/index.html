2. 유튜브 연결

Google Cloud에서 만든 OAuth 클라이언트 파일(데스크톱 앱 유형, JSON)을 등록한 뒤 계정을 연결합니다. 자세한 방법은 저장소의 docs/SETUP.md를 보세요.

JSON 파일 대신 클라이언트 ID와 보안 비밀번호를 붙여넣어도 됩니다.

3. 채널 정체성 파일
