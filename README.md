# G-UPLOADER

영상 파일을 넣으면 내 채널 말투로 **유튜브 제목·설명·해시태그·태그 3가지 버전**을 만들어 주고, 고른 내용을 유튜브 영상에 바로 적용해 주는 프로그램입니다. 모든 처리는 내 PC에서 하고, 키와 로그인 정보도 내 PC에만 저장됩니다.

## 이렇게 동작합니다

1. 유튜브 스튜디오에서 영상을 **비공개**로 업로드합니다.
2. G-UPLOADER에 같은 영상 파일을 넣습니다 (끌어다 놓기 또는 파일 선택).
3. 프로그램이 알아서 분석합니다.
   - 숏폼/롱폼 판별 (길이 3분 이하 + 세로·정사각형이면 숏폼)
   - 로컬 Whisper로 음성 인식 (NVIDIA 그래픽카드가 있으면 자동으로 사용)
   - 장면 캡처 분석
   - 내 채널의 조회수 높은 제목 참고
4. **검색형 · 클릭형 · 채널톤형** 3가지 버전이 나옵니다. 버전 전체를 고르거나 제목·설명·해시태그를 다른 버전끼리 섞어 고를 수 있고, 직접 고칠 수도 있습니다.
5. 썸네일, AI 사용 표시, 유료 프로모션 표시, 카테고리, 예약 공개를 정하고 **[세팅 적용]** → **[공개]**.

업로드한 영상은 원본 파일명으로 자동으로 찾습니다.

## 썸네일 스튜디오

결과 화면의 **[썸네일 스튜디오에서 만들기]**를 누르면 거나두잇 썸네일 스튜디오(레이어 편집기, 템플릿 5종, 글꼴 35종)가 열립니다. 분석한 영상이 자동으로 들어가 장면 8장이 뽑히고, AI가 쓴 썸네일 문구(라벨·지역·두 줄 제목)가 "여행 에피소드" 템플릿에 채워집니다. 다듬은 뒤 **[G-UPLOADER에 적용]**을 누르면 업로드할 때 함께 올라갑니다.

- 배경 레이어 → **사진 보정**: 밝기·대비·채도·색온도·선명도·비네팅·흐림, 프리셋(자동 보정, 따뜻한 여행, 선명하게, 차분한 다큐)
- 배경 레이어 → **고화질**: [선명한 원본 화질로]는 고른 장면 앞뒤 0.8초를 원본 해상도로 다시 뽑아 가장 선명한 프레임으로 교체, [AI 업스케일]은 Real-ESRGAN(처음 한 번 약 45MB 내려받음, BSD 라이선스)으로 디테일 복원
- 스튜디오 원본: `app/static/studio/studio.orig.html` (드라이브 '거나두잇 썸네일 스튜디오/01_실행파일'의 v8)
- 새 버전으로 바꿀 때: 원본만 교체하고 `.venv\Scripts\python.exe tools\build_studio.py` 실행
- 글꼴 Pretendard는 SIL 오픈 폰트 라이선스(`app/static/fonts/OFL-Pretendard.txt`)

## AI 티가 덜 나게 하는 장치

- **채널 정체성 파일**: 말투, 금지 표현, 제목 규칙, 고유명사, 설명란 고정 문구를 마크다운 파일 하나로 관리합니다. ([예시](templates/identity.example.md))
- **내 채널 과거 제목 학습**: 조회수 높은 내 영상 제목의 길이·어미·기호 습관을 따라 씁니다.
- **자동 점검**: 금지 표현("따옴표"로 적은 것)이 들어가거나 길이 제한을 넘으면 자동으로 다시 씁니다.

## 설치

### 일반 사용자 (Windows)

[Releases](../../releases)에서 `G-UPLOADER-Setup-x.y.z.exe`를 받아 설치하세요. 새 버전이 나오면 프로그램 상단에 **업데이트** 버튼이 나타나고, 누르면 자동으로 덮어쓰기 설치됩니다. 설정과 정체성 파일은 유지됩니다.

프로그램은 자체 창으로 열리고, 창을 닫으면 종료됩니다. 분석이나 업로드 중에 닫으려 하면 한 번 더 물어봅니다. 실행 기록은 `%APPDATA%\G-UPLOADER\logs`에 남습니다.

> 처음 실행할 때 Windows가 "PC를 보호했습니다"를 띄우면 **추가 정보 → 실행**을 누르세요. 서명되지 않은 오픈소스 프로그램이라 나오는 경고입니다.

### 소스로 실행 (개발자)

Python 3.12와 ffmpeg가 필요합니다.

```powershell
git clone https://github.com/geon9892-dev/G-UPLOADER.git
cd G-UPLOADER
.\start.bat
```

`start.bat`이 처음 한 번 가상환경과 필요한 패키지를 설치합니다(NVIDIA 그래픽카드가 있으면 GPU 라이브러리도). 업데이트는 `git pull`.

## 처음 설정

프로그램을 처음 켜면 설정 화면이 열립니다. 자세한 방법은 [docs/SETUP.md](docs/SETUP.md)를 보세요.

1. **Claude API 키**: 제목과 설명을 쓰는 AI. 영상 1개당 대략 수십~수백 원.
2. **유튜브 연결**: Google Cloud에서 OAuth 클라이언트 파일을 만들어 등록한 뒤 계정 연결 (무료).
3. **채널 정체성 파일**: 내 채널에 맞게 수정.

## 데이터 저장 위치

| 내용 | 위치 |
|---|---|
| 프로그램 | 설치 폴더 (업데이트 때 덮어씀) |
| 설정, 암호화된 키, 정체성 파일, 작업 기록, Whisper 모델 | `%APPDATA%\G-UPLOADER` (업데이트해도 유지) |

## 알아둘 점

- 유튜브 API는 하루 사용량(기본 10,000 유닛)이 있습니다. 영상 1개 적용에 약 100~200 유닛을 씁니다.
- 숏폼 썸네일은 API로 올려도 숏폼 피드에 표시되지 않아, 유튜브 앱에서 프레임을 골라야 합니다.
- 맞춤 썸네일은 채널 전화번호 인증이 되어 있어야 올라갑니다.
- 영상 옆에 같은 이름의 `.srt` 자막 파일이 있으면 음성 인식 대신 그 자막을 씁니다.
